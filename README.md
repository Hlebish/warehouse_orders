# Заказы · Склад

Адаптивный PWA-предпросмотр приложения для кладовщика и менеджеров. Интерфейс рассчитан на телефон и компьютер.

## Что уже работает в предпросмотре

- создание карточки по номеру заказа и имени клиента;
- статусы «Собран», «Под вопросом», «На согласовании», «Одобрен на отгрузку клиенту» и «Отменён»;
- любое число комментариев и дефектов с артикулом и фотографиями;
- действия менеджера: отметить просмотр, начать согласование, одобрить к отгрузке, отменить с обязательной причиной;
- подтверждение/отмена отдельного дефекта с комментарием;
- директорское удаление карточки с отдельной записью в журнале действий;
- поиск, фильтры, локальная лента уведомлений, мобильная раскладка.

## Важно: текущий режим — локальный предпросмотр

В этой версии данные хранятся в `localStorage` текущего браузера. Они не синхронизируются между устройствами и сотрудниками; реальные push-уведомления ещё не подключены. Переключение ролей служит только для просмотра интерфейса и не является защитой доступа. Не используйте этот режим для рабочих заказов или реальных персональных данных.

## Запуск

Откройте `index.html` в браузере. Для установки как PWA и service worker нужен локальный HTTP-сервер или HTTPS-хостинг. Например, из этой папки:

```powershell
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Подключение общей рабочей версии на Firebase

Для перехода из предпросмотра в реальную совместную систему нужно добавить Firebase Authentication, Cloud Firestore, Cloud Storage и FCM, настроить серверные функции для приглашения сотрудников и отправки push, затем выложить приложение на HTTPS-хостинг. Правила доступа должны проверять роль сотрудника: только директор удаляет записи, а кладовщик и менеджеры могут выполнять только разрешённые действия. Демо-данные в `app.js` не переносить.

Веб-push зависит от поддержки браузера и разрешения пользователя. На телефоне приложение можно добавить на главный экран; для push потребуется HTTPS, регистрация service worker и настройка Firebase Cloud Messaging для проекта.

## Структура

- `index.html` — интерфейс;
- `styles.css` — оформление и мобильная версия;
- `app.js` — демо-логика;
- `manifest.webmanifest`, `sw.js` — базовая оболочка PWA.
- `amp-logo.png` — логотип AMP в интерфейсе.
